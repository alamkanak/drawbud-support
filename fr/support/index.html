Dessiner sur papier

Explorez un dessin ou suivez un Parcours. Le dessin, les supports visuels et le guide vocal se téléchargent ensemble. Utilisez Précédent, Suivant et Rejouer. Le mode mains libres fait avancer les étapes après une pause pour dessiner.

Bibliothèque et compte

Les leçons dans Bibliothèque → Hors ligne fonctionnent sans connexion. Un compte facultatif synchronise la pratique entre vos appareils. Supprimer un téléchargement ne supprime pas l’historique en ligne.

Supprimer un compte

Ouvrez Drawbud → Réglages → Supprimer le compte, puis confirmez. Le compte et la progression en ligne sont supprimés. Si vous ne pouvez pas accéder à l’app, écrivez à alam.kanak@gmail.com. Ne publiez jamais de mot de passe ni de données personnelles dans un signalement public.

Confidentialité

Drawbud utilise une identité invitée privée et conserve la progression, les exercices et les dessins enregistrés dans Supabase. L’e-mail est facultatif. Les téléchargements et préférences restent sur votre appareil. Aucun dessin sur papier n’est collecté. Aucune publicité, analyse tierce ou suivi entre applications. Supabase et GitHub Pages traitent les informations techniques habituelles des requêtes. Les rappels sont locaux et facultatifs. L’espace créateur utilise le stockage du navigateur pour la session administrateur et les copies de secours des brouillons propres au compte. Pour une demande d’accès, correction ou suppression, écrivez à alam.kanak@gmail.com. Les sauvegardes et journaux suivent les durées des fournisseurs. Un parent doit gérer les comptes des jeunes enfants. La politique complète en anglais se trouve dans la page Privacy.
